# 🤖 AI Customer Support System

An AI-powered Customer Support System built using the **MERN Stack** and **Google Gemini AI**. It allows users to securely register, log in, and interact with an intelligent AI assistant that provides instant responses to customer queries.

---

## 🌐 Live Demo

**Frontend (Vercel)**  
👉 https://ai-customer-support-system-beta.vercel.app/

**GitHub Repository**  
👉 https://github.com/sunildas-dev/AI-Customer-Support-System

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/sunildas-dev/AI-Customer-Support-System.git
```

---

## Backend

```bash
cd backend
npm install
npm run dev
```

Create a `.env`

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key
```

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```

Create a `.env`

```env
VITE_API_URL=http://localhost:5000/api
```
